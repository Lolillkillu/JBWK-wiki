Mechanical Keyboard PCB

Keyboard printed circuit board — matrix, microcontroller, passive components, connectors and protection circuits

Terminology note
The printed circuit board (PCB) of a mechanical keyboard constitutes the central electronic component of the input device. Its function encompasses the acquisition of signals from key switches, their processing into digital data, and transmission to the computer via the USB interface. The PCB integrates all electronic components — the microcontroller, isolation diodes, resistors, capacitors, crystal oscillator, and USB connector — into a single functional circuit.

In keyboard architecture, the keyboard matrix constitutes the input circuit topology, while the microcontroller acts as the processing unit. Correct operation of the whole requires close cooperation between the hardware layer (PCB layout) and the firmware layer — including matching the matrix orientation in hardware with the definition in firmware.

Keyboard Matrix

  • Keyboard matrix A circuit topology in which key switches are placed at the intersections of row and column lines. This architecture significantly reduces the number of microcontroller I/O lines required — a matrix of m rows and n columns requires only m + n pins to handle m × n switches. The process of reading key states (matrix scanning) involves cyclically activating rows or columns while simultaneously reading the state of lines configured as inputs.
  • COL2ROW A matrix configuration where columns function as outputs and rows as inputs. Isolation diodes (if present) are oriented with the cathode towards the row line. This is the dominant configuration in the QMK firmware ecosystem. Correct keyboard operation requires the matrix orientation in the hardware layer to match the definition in the firmware.
  • ROW2COL A matrix configuration where rows function as outputs and columns as inputs. In the active-high logic used by some designs, the cathodes of the isolation diodes are directed towards the column line. However, in the more common active-low (pull-up) configuration used in QMK/AVR, current flows into the output pin and the cathode must be directed towards the row. Less common than COL2ROW, but used in select designs. As with COL2ROW, the hardware orientation must correspond to the firmware definition.

Isolation Diodes

  • Ghosting The phenomenon of falsely registering a key press that was not actually pressed. It occurs in a matrix without diodes when three keys forming three vertices of a rectangle are pressed simultaneously — current flows along an undesired path (sneak path), creating the illusion of a fourth key being pressed at the intersection of the remaining lines. Eliminating ghosting requires placing a diode in series with each switch.
  • Isolation diodes and NKRO A diode placed in series with a switch conducts current in only one direction (from anode to cathode), effectively blocking sneak paths and eliminating ghosting. The use of isolation diodes enables N-key rollover (NKRO) — the simultaneous recognition of any number of pressed keys without generating false signals.
  • 1N4148 A standard switching diode in a through-hole DO-35 package. The most commonly used diode type in through-hole mounted (THT) keyboards. Forward current 200 mA, breakdown voltage 75 V, switching time 4 ns.
  • 1N4148W The SMD equivalent of the 1N4148 diode in a SOD-123 package. A standard surface-mount component used in surface-mount keyboards. Electrical specifications are identical to the through-hole version.
  • 1N4148WS A miniaturized variant of the 1N4148 diode in a SOD-323 package. Used in designs with limited PCB space, e.g., split keyboards with a compact layout.
  • BAV70 A dual diode in a SOT-23 package with a common cathode, allowing two keys to be handled by a single component. Reduces the number of components on the PCB and the mounting area. Electrical specifications are similar to the 1N4148.

Microcontroller

  • Microcontroller (MCU) The central control unit of the keyboard. It is responsible for cyclic matrix scanning, debouncing (eliminating contact bounce), encoding presses into the HID (Human Interface Device) protocol, and transmitting data via USB to the computer. The number of available GPIO pins determines the maximum size of the keyboard matrix and the ability to support additional features: RGB lighting, rotary encoders, or OLED displays.

Resistors

  • Pull-up and pull-down resistors Digital inputs of a microcontroller in a disconnected (floating) state have an undefined logic level, susceptible to fluctuations caused by electromagnetic interference. CMOS inputs have very high input impedance, causing them to act like antennas picking up 50/60 Hz mains hum and other noise from the environment. Pull-up resistors (tied to the power supply) and pull-down resistors (tied to ground) enforce a default, known logic state on input lines. In a keyboard matrix, they are used on lines configured as inputs. Many modern microcontrollers (RP2040, ATmega32U4) have these resistors built-in and they can be activated in software, eliminating the need for external components.
  • Reset circuit resistors The microcontroller's reset pin must remain high during normal operation. A pull-up resistor connected to the RESET pin provides a stable logic level and prevents accidental system restarts due to interference. Parallel to this resistor, a button is connected that shorts the pin to ground, allowing a manual reset. Typical resistor value: 10 kΩ.
  • Bootloader configuration resistors In ATmega32U4 chips, the HWB (Hardware Boot) pin requires a pull-down resistor to ground so that upon pressing the reset button, the microcontroller enters bootloader mode, allowing firmware programming via USB. This resistor (typically 10 kΩ) holds the HWB pin low, which is a condition for entering DFU programming mode.
  • USB line series resistors Series resistors with values on the order of tens of ohms (typically 22 Ω or 27 Ω) are mounted on the USB data lines (D+ and D−). Their primary purpose is impedance matching — together with the driver output impedance inside the MCU they approximate the 45 Ω single-ended / 90 Ω differential characteristic impedance of USB 2.0 Full Speed — and damping signal reflections at high frequencies, which improves data transmission integrity. They also provide limited protection against small voltage spikes on the data lines. They should be placed as close to the microcontroller pins as possible.

Capacitors and Crystal Oscillator

  • Decoupling capacitors Microcontrollers and other digital ICs generate short, rapid current spikes during logic state transitions. Decoupling capacitors are mounted as close as possible to the microcontroller's VCC/GND power pins. Typically, 100 nF ceramic capacitors are used at each pair of power pins, along with an electrolytic or ceramic capacitor of several microfarads at the main power input. Their role is to store charge locally and supply the IC during spikes, preventing voltage drops and interference.
  • Crystal load capacitors A crystal oscillator requires two load capacitors to operate properly, typically with capacitances on the order of tens of picofarads. The value is selected based on the crystal's parameters (its load capacitance). These capacitors form a resonant circuit with the crystal, which determines the exact clock frequency of the microcontroller.
  • UCap pin capacitor In the ATmega32U4, the UCap pin requires an external capacitor of approximately 1 µF connected to ground. This capacitor stabilizes the internal 3.3 V voltage regulator of the USB peripheral, ensuring proper communication on the USB bus.
  • Crystal oscillator Provides the microcontroller with a stable clock signal that synchronizes all digital operations, including matrix scanning and USB communication. For the ATmega32U4, a 16 MHz crystal oscillator is typically used. The crystal must be placed as close to the microcontroller pins as possible, and the traces leading to it should be short and symmetrical to minimize interference and ensure oscillation stability. Some microcontrollers (e.g., RP2040) have an internal oscillator and do not require an external crystal.

USB Connector and Protection Circuits

  • USB connector The main communication and power interface of the keyboard. Modern designs increasingly use USB-C due to its reversible plug orientation. Older or budget designs still feature Mini-B or Micro-B connectors. The USB-C connector requires additional configuration resistors on the CC1/CC2 pins.
  • ESD protection Electrostatic Discharge (ESD) protection devices, such as the PRTR5V0U2X, are mounted on the USB data lines (D+, D−) and often on the power line. They drain short, high-voltage static spikes to ground, which could otherwise damage sensitive digital circuitry of the microcontroller. They are a critical element for keyboard reliability, especially since the port is exposed to statically charged users.
  • Polyfuse A polymer fuse mounted in series with the VBUS power line. If the allowable current is exceeded (e.g., during a short circuit), it increases its resistance, cutting off power to the rest of the circuit. Once the cause of the overload is removed, the fuse automatically returns to its original state. Typical trip current for keyboards: 500 mA.
  • USB-C configuration resistors In USB-C connectors, the CC1 and CC2 pins (Configuration Channel) are used to detect plug orientation, connection presence, and current negotiation. They require external 5.1 kΩ pull-down resistors (for a device mode downstream facing port). The SBU1 and SBU2 pins remain unused in keyboards.

Buttons and Programming Interface

  • Reset button An electromechanical component (tactile switch) that allows manual restarting of the microcontroller. It shorts the RESET pin to ground, forcing the IC to reinitialize. In the custom keyboard ecosystem, this button is crucial for programming and updating the firmware.
  • Bootloader mode A special microcontroller operating mode that allows firmware programming or updating via USB without the need for an external hardware programmer. In ATmega32U4 chips, activation requires pressing the reset button while the HWB pin is held low. In chips with a DFU bootloader (e.g., STM32), this mode is activated by tying the boot0 pin high and resetting. Some boards (e.g., Pro Micro) automatically enter bootloader mode for a short time after a reset (Caterina bootloader). In modern designs using the RP2040, bootloader mode is entered by holding the BOOTSEL button during power-up or reset, which disconnects the Flash and exposes the device as a USB mass-storage drive.

Electrostatic Capacitive (EC) Switches

  • Electrostatic capacitive sensing principle The EC switch operates on the principle of variable capacitance. A conductive spring and a fixed electrode on the PCB form a parallel-plate capacitor whose capacitance is described by C = ε₀εᵣA/d, where d is the distance between the spring and the electrode. Pressing the key compresses the rubber dome, reducing d and increasing capacitance. The controller detects this change by measuring charge/discharge time or integrating a displacement current. Because the system does not rely on ohmic contact, the switch is inherently debounced and offers a lifespan exceeding 50 million actuations.
  • EC matrix and electrode layout Unlike a mechanical matrix, the EC PCB contains a grid of copper electrodes (pads) on the top layer, each positioned directly beneath the switch spring. Rows are typically driven with short voltage pulses (burst scanning), while columns are read as analog inputs. The high input impedance of the sensing circuit (often >1 MΩ) is necessary to prevent leakage currents from distorting the femtofarad-scale capacitance changes. This topology natively supports N-key rollover because each key forms an independent capacitive node.
  • Operational amplifier and comparator stage The raw capacitive signal is too weak for direct ADC sampling. A transimpedance or charge-amplifier stage (built around a low-offset op-amp) converts the capacitive change into a voltage swing. Alternatively, a comparator with hysteresis (Schmitt trigger) thresholds the analog level into a digital press/release state. The hysteresis window (typically tens of millivolts) prevents chatter caused by mechanical vibration of the spring. Some designs use a synchronous demodulator to suppress 50/60 Hz mains hum picked up by the large-area electrodes.
  • Scanning speed and polling optimization To achieve a 1 ms polling interval, the firmware applies a burst of excitation pulses to each row in rapid succession (time-division multiplexing). The column signals are sampled immediately after each burst, before the RC time constant of the electrode decays. The use of a fast ARM Cortex-M4 microcontroller (e.g., STM32F411 at 100 MHz) with a multi-channel DMA-driven ADC allows parallel sampling of multiple columns, reducing the total matrix scan time to microseconds.

Hall Effect Sensors

  • Hall effect physical principle The Hall effect arises from the Lorentz force acting on charge carriers in a semiconductor. When a bias current I flows through a Hall element perpendicular to an applied magnetic field B, a transverse voltage VH = (I·B)/(n·e·t) appears perpendicular to both the current and the magnetic field, where n is the carrier density, e the elementary charge, and t the element thickness. In keyboard switches, a permanent magnet embedded in the stem moves relative to a surface-mount Hall sensor (e.g., OH49E, SS49E), causing the perpendicular component of B at the sensor to vary linearly with key travel.
  • Analog Hall sensor and ADC interface Linear Hall sensors output an analog voltage (typically 0.5–4.5 V for a 5 V supply) proportional to the magnetic flux density. On the PCB, each sensor requires a stable power rail (3.3 V or 5 V) and a decoupling capacitor (100 nF) to suppress noise from the switching magnet. The output is routed to the microcontroller's ADC pin, either directly or through an analog multiplexer (e.g., 74HC4067) if the MCU has insufficient analog channels. The ADC resolution (usually 12-bit) determines the minimum detectable travel increment, enabling sub-millimeter actuation-point adjustment in firmware.
  • Hall matrix architecture Because Hall sensors are active devices requiring continuous power, a traditional diode-isolated matrix is unsuitable. Instead, the PCB routes power and ground in parallel to all sensors, while the outputs are wired in a row/column grid read by multiplexers or a dedicated ADC-per-column scheme. Some designs employ a 1×n linear scan with a single multiplexer and a sample-and-hold circuit. Others use a dedicated Hall-ADC IC with an I²C/SPI interface to reduce pin count. The absence of contact bounce eliminates the need for software debouncing, though median filtering is often applied to ADC samples to reduce magnetic noise.
  • Power and thermal considerations A linear Hall sensor draws a quiescent current of 3–10 mA (modern keyboard-dedicated sensors may operate at 2–3 mA or feature power-saving modes). In a 100-key keyboard, the total sensor current can approach 500–800 mA in the worst case, exceeding the 500 mA standard USB limit. The PCB must therefore include either an external 5 V power input or a high-efficiency buck regulator to supply the sensors. The copper pours around the sensor array should be thermally connected to the ground plane to dissipate heat, as the sensors' offset voltage drifts with temperature (typical coefficient: ±0.1 %/°C).

TMR (Tunnel MagnetoResistance) Sensors

  • TMR physical principle Tunnel MagnetoResistance exploits spin-dependent quantum tunneling through an ultra-thin insulating barrier (typically MgO) sandwiched between two ferromagnetic layers. The resistance of the stack depends on the relative orientation of the magnetizations: R(θ) = Rmin + (Rmax − Rmin)·sin²(θ/2), where θ is the angle between the layers. In keyboard PCBs, the TMR sensor detects the in-plane component of the magnetic field from the switch magnet, yielding a resistance change orders of magnitude larger than the Hall voltage for the same field strength.
  • TMR vs. Hall effect on PCB While Hall sensors measure the perpendicular component of B via carrier deflection, TMR sensors measure the in-plane component via magnetization rotation in a free ferromagnetic layer. The TMR effect produces a relative resistance change of 100–600 %, compared to <0.1 % for Hall elements. Consequently, TMR sensors require less gain and simpler readout circuitry—often just a Wheatstone bridge or a constant-current source with a single-ended amplifier. The sensor footprint (SOT-23 or smaller) is comparable to Hall ICs, but the sensitivity is roughly three orders of magnitude higher.
  • Power efficiency and thermal stability TMR sensors consume 0.001–0.01 mA per channel, roughly 1000× less than analog Hall arrays (5–10 mA). This makes TMR the preferred technology for wireless keyboards, where battery life is critical. Additionally, the TMR stack retains its magnetic properties up to 200 °C (compared to ~150 °C for Hall elements), reducing temperature drift in the actuation threshold. The PCB layout should minimize trace length between the TMR bridge and the instrumentation amplifier to reduce thermoelectric offsets from copper-to-solder junctions.
  • Actuation precision and rapid trigger The high signal-to-noise ratio of TMR bridges enables 0.01 mm actuation resolution. The firmware implements a hysteresis comparator with programmable upper and lower thresholds around the magnet's travel curve. Because the TMR response is monotonic and fast (bandwidth >1 MHz), the controller can detect direction reversal (rapid trigger) within a single polling cycle, eliminating the dead zone inherent in mechanical contacts. The PCB must route the sensor supply through a low-noise LDO and shield the analog traces from USB data-line crosstalk to preserve this precision.
